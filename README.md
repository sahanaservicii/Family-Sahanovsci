# Семейный портал — каркас сайта

Статический офлайн-каркас сайта для общения семьи и гостевой информации.
Реальные устройства, Home Assistant и аккаунты **не подключаются** — только витрина
и демонстрационные данные. Внешних библиотек, CDN и сетевых запросов нет.

## Состав

```
family-site/
├── index.html          # одна точка входа, хеш-навигация
├── assets/
│   ├── style.css       # стили, адаптив
│   ├── data.js         # демонстрационные данные: члены семьи, модули, новости
│   └── app.js          # рендер разделов, кабинеты, гостевая книга
└── README.md
```

## Разделы

- `#/home` — главная с разделением на **«Для семьи»** и **«Для гостей»**.
- `#/family` — выбор личного кабинета; у каждого члена семьи свой набор модулей.
- `#/cabinet/<id>/<module>` — личный кабинет: обзор, умный дом, устройства,
  личные данные, задачи, расписание, заметки, настройки (набор зависит от профиля).
- `#/guest` — гостевая витрина и демонстрационная гостевая книга.

Гостевая книга хранит записи в `localStorage` этого браузера (до 30 записей).
Выключатели «умного дома» и чекбоксы задач работают только в памяти страницы.

## Запуск локально

Из папки `/root/workspace/family-site`:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8080/`. Можно также просто открыть `index.html`
в браузере с файловой системы — всё работает без сервера.

## Открытие сайта из интернета (GitHub Pages)

После включения Pages в настройках репозитория сайт будет доступен по адресу:

**https://sahanaservicii.github.io/Family-Sahanovsci/**

Включение (один раз, в веб-интерфейсе GitHub):
1. Открыть https://github.com/sahanaservicii/Family-Sahanovsci/settings/pages
2. Build and deployment → Source → **Deploy from a branch**
3. Branch → **main**, папка **/(root)** → Save
4. Подождать 1–2 минуты и открыть ссылку выше.

Ссылка открывается на телефоне, планшете и компьютере — достаточно браузера.
Разделы «Для семьи» и кабинеты доступны всем, у кого есть ссылка: это публичный сайт
без входа. Если появятся реальные личные данные — включите авторизацию или уберите
кабинеты из публичной сборки.

## Публикация на GitHub

Сайт публикуется отдельным репозиторием `Family-Sahanovsci` (только эта папка,
без ключей, бэкапов и конфигов homelab). Доступ — по уже настроенному SSH-ключу,
через `git@github.com:sahanaservicii/Family-Sahanovsci.git`.

```bash
python3 /root/workspace/homelab/site_github_sync.py init     # один раз
python3 /root/workspace/homelab/site_github_sync.py sync --message "site: update"
python3 /root/workspace/homelab/site_github_sync.py status
```

После `init` устанавливается хук `post-commit`: каждый коммит в этой папке
автоматически пушится в `main`. Если GitHub недоступен, коммит остаётся локально,
а причина записывается в `/root/workspace/homelab/state/site_github_push.log`.
