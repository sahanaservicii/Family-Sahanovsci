# Семейные фото

Сюда кладутся файлы галереи. Сайт ничего не загружает из интернета — только эти локальные файлы.

## Как добавить фото

1. Положите файлы в эту папку, например `family-01.jpg`, `family-02.jpg` и т.д.
2. В файле `../data.js` в разделе `window.SITE_DATA.gallery` уже прописаны 6 слотов:
   `family-01.jpg` … `family-06.jpg`. Если имя файла другое — замените путь в нужном слоте.
3. Там же можно поменять `title` и `caption` — подписи под фото.
4. Запушьте изменения:
   ```bash
   python3 /root/workspace/homelab/site_github_sync.py sync --message "site: add family photos"
   ```

Пока файла нет, на его месте показывается рамка с именем ожидаемого файла.

Форматы: JPG, PNG, WebP — любые, которые умеет браузер. Размер одного фото желательно до 1–2 МБ,
чтобы страница открывалась быстро на телефоне.

**Важно:** сайт публичный и без входа. Фото из раздела «Для семьи» видны всем, у кого есть
ссылка на сайт, — галерея спрятана только от гостевой вкладки, но не защищена паролем.
